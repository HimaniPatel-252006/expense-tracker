Built a full-stack Expense Tracker application using Flask (Python) and SQLite, enabling users to add, view, and delete categorized expenses with dynamic total calculation and a responsive frontend using HTML, CSS, and JavaScript.

## Description
A simple expense tracker using Flask and SQLite.

## Features
- Add expenses
- View expenses
- Store data in database

## Tech Used
- Python (Flask)
- HTML/CSS
- SQLite

## How to Run
1. Install Flask
2. Run app.py
3. Open browser at localhost
